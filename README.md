# FPGA and DFX (Dynamic Function eXchange) Workshop

## 📌 Overview

This repository contains the learning materials, presentations, and hands-on exercises for a **3-day FPGA and Dynamic Function eXchange (DFX)** workshop. The workshop introduces FPGA fundamentals, explores DFX concepts, and concludes with a mini hackathon where participants apply their learning through practical implementation.

---

## 🎯 Learning Objectives

By the end of this workshop, participants will be able to:

* Understand FPGA architecture and terminology.
* Compare FPGAs with MPUs, MCUs, GPUs, and ASICs.
* Design and implement FPGA applications using Vivado.
* Understand Dynamic Function eXchange (DFX) concepts and workflow.
* Build simple DFX designs using reconfigurable partitions.
* Apply FPGA and DFX concepts in a mini hackathon.
  
📅 Workshop Schedule
Day 1 – FPGA Fundamentals
**Topics**
* Introduction to digital hardware platforms
* MPU vs MCU vs GPU vs ASIC vs FPGA
* FPGA history and applications
* FPGA architecture and terminology
* CLBs, LUTs, Flip-Flops, DSPs, BRAM, Routing, and I/O Blocks
**Hands-on**
* Matrix Multiplication **without BRAM**
* Matrix Multiplication **using BRAM**
### **Day 2 – Dynamic Function eXchange (DFX)**
**Topics**
* Introduction to DFX
* Evolution from Partial Reconfiguration
* Benefits and applications
* Real-world analogies
* DFX terminology:
 * Static & Reconfigurable Regions
  * Reconfigurable Modules
  * Partition Pins
  * Pblocks
  * Full & Partial Bitstreams
**Hands-on**

* Single Pblock DFX design
* Dual Pblock DFX design
### **Day 3 – Mini Hackathon**
Participants work in teams to develop an FPGA/DFX-based solution using the concepts learned throughout the workshop.
**Focus Areas**
* FPGA design
* DFX implementation
* Team collaboration
* Final project demonstration
## 🛠 Software Requirements
* Xilinx Vivado Design Suite
* FPGA Development Board
* Programming Cable
* Basic Verilog/VHDL knowledge
